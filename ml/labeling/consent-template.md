# Consentimiento para corpus

Autorizo el uso de mi consulta, previamente anonimizada, para investigación y mejora del sistema Ciudadano AI. Entiendo que la participación es voluntaria, puedo revocarla y la consulta no contiene números de documento, teléfonos, correos ni otros datos personales. Finalidad, retención, responsable y canal de eliminación deben completarse antes de recolectar datos reales.
