# Guía de etiquetado

Asignar una sola intención primaria: información general, solicitud de realizar/obtener un trámite, verificación de estado de una gestión existente, reporte de problema o derivación explícita a una entidad. Marcar mensajes ambiguos para revisión, no adivinar. Dos revisores independientes etiquetan una muestra; un tercer revisor resuelve desacuerdos. Anonimizar identificadores antes de verlos y registrar fuente, fecha, versión y consentimiento.
