# Matriz ISO/IEC 25010

| Característica | Métrica | Prueba | Evidencia | Aceptación |
|---|---|---|---|---|
| Adecuación funcional | F1 por intención, casos cubiertos | `ml/evaluation/evaluate.py` | JSON generado | F1 macro >= 0.70 |
| Eficiencia | media/p50/p95/p99/error | JMeter 500 | CSV/HTML | normal < 800 ms |
| Compatibilidad | contrato OpenAPI | contract tests | openapi.yaml | sin breaking changes |
| Usabilidad | SUS, éxito, duración | protocolo SUS | research/sus | SUS >= 68 |
| Fiabilidad | fallos recuperados | resiliencia | bitácora | fallback seguro |
| Seguridad | severidad ZAP | baseline/API/auth scan | reports | sin high/critical CVSS > 7 |
| Mantenibilidad | cobertura, complejidad | Vitest/pytest/CI | reportes | >= 80% |
| Portabilidad | despliegue Compose/K8s | smoke deploy | manifiestos | reproducible |
