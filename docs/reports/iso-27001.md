# Matriz ISO/IEC 27001 (implementación vs dependencia)

| Control | Aplicación | Infraestructura/proveedor | Evidencia |
|---|---|---|---|
| Acceso y mínimo privilegio | JWT, roles/permisos, revocación | IAM, RBAC de cluster | auth-service |
| Criptografía | bcrypt, anonimización, hashes de auditoría | TLS 1.3, AES-256/KMS | tls + deployment |
| Desarrollo seguro | Zod/Pydantic, límites, consultas parametrizadas | CI, escaneo de imágenes | tests + ZAP |
| Incidentes/auditoría | eventos inmutables y security events | SIEM, alertas, retención | audit-service |
| Continuidad | retries, circuit breaker, probes, graceful shutdown | backups, multi-AZ | resilience |
