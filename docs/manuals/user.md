# Uso ciudadano

1. Abrir el catálogo público sin autorizar el chat, o entrar al asistente y leer/aceptar el consentimiento.
2. Escribir en español hasta 500 caracteres. Evitar datos personales; el sistema elimina patrones de correos, documentos y teléfonos antes de PLN.
3. Consultar requisitos y fuentes. Una pregunta siguiente puede mantener el trámite. Si falta precisión, responder la aclaración; tras dos fallos se ofrece el canal oficial.
4. Verificar costos, plazos, horarios y antigüedad directamente con la entidad. El asistente orienta; no ejecuta trámites.
5. Usar el formulario de seguimiento para una solicitud propia. En el prototipo: ciudadano-demo@example.test, OTP mostrado y DEMO-001. El resultado dice simulado.
6. Reportar respuestas útiles o incorrectas. Privacidad permite consultar/descargar datos, controlar cada finalidad y eliminar el perfil con comprobante.
7. La sesión vence tras quince minutos sin actividad. Alto contraste, tamaño de letra, lectura y dictado son opcionales; la voz depende del navegador.
