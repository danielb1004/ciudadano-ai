# Manual de entrenamiento

Importa consultas autorizadas, anonimiza, etiqueta con doble revisión y exporta JSONL. Versiona corpus, guía, procedencia y dataset card. Ejecuta la línea base TF-IDF y después prepara BETO con `python3 ml/training/train_beto.py --data <corpus>`. Nunca entrenar al iniciar un servicio.
